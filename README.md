# Abyss Run — 2D 픽셀 던전 RPG

**접속: https://abyss-run.nyoonsung0412.workers.dev** — 링크 열고 아이디·비밀번호로 회원가입하면 바로 플레이

모험가로 시작해 1~100층 던전을 공략하는 웹 브라우저 멀티플레이 RPG.
전투는 **서버가 전부 계산**하고 브라우저는 입력만 보내는 구조라 클라이언트 조작(속도핵·데미지 조작 등)이 통하지 않습니다.
이동은 내 화면에서 바로 반응하고(지연 없음), 서버가 확인한 위치와 조용히 맞춥니다.

- 7직업(검사·권투사·궁수·도적·마법사·성직자·대장장이) + 모험가, 기획서 스킬 전부(공용 4 + 직업 스킬 101개)
- 1~100층, 층마다 방 모양 10가지(기둥 홀·십자방·팔각방·원형방·섬·강과 다리·칸막이·잔해·웅덩이), 5층마다 중간보스·10층마다 주요 보스(총 20종), 10층 전직소
- 솔로 / 최대 4인 실시간 파티, 개인 드롭
- 장비 5부위, 등급 일반·희귀·영웅·전설·신화(0.5%), **쿨타임 감소 효과 없음**
- 강화 +99까지: +n→+n+1 성공 (99−n)%, 파괴 항상 1%
- 관리자 페이지(`/gm`): 서버 현황, 플레이어 검색·수정·아이템 지급/회수·킥·차단·채금·층 이동·임시 비밀번호 발급, 공지, 관리 기록, 보안 로그
- 그래픽: 캐릭터·몬스터·타일 [0x72 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)(CC0, 구역·직업별 색 입힘), 마을·주민·수정 [Ninja Adventure](https://pixel-boy.itch.io/ninja-adventure-asset-pack)(CC0), 이펙트 [pixelfx](https://github.com/patch-gg/pixelfx)(MIT), [Galmuri](https://github.com/quiple/galmuri)(OFL) 픽셀 폰트
- 타격감: 히트스톱(공격자·대상 함께), 흰색 번쩍임·찌그러짐, 밀림, 불꽃 입자, 카메라 반동, 효과음(Web Audio 합성), 휴대폰 진동

## 관리자

- GM 계정은 없습니다. `/gm`(https://abyss-run.nyoonsung0412.workers.dev/gm)에 **처음 들어온 사람이 관리자 비밀번호를 정합니다.** 그 뒤로는 그 비밀번호로만 들어옵니다.
- 관리자 페이지 위쪽 **비밀번호 변경**으로 바꿀 수 있어요.
- 관리자 비밀번호를 잊었다면: Cloudflare → Workers → abyss-run → Settings → Variables and Secrets 에 비밀값 `ADMIN_KEY`를 추가하고, 그 값으로 로그인한 뒤 비밀번호 변경.
- 플레이어가 비밀번호를 잊으면: 관리자 페이지 → 플레이어 → **임시 비밀번호 발급**

## 배포

GitHub `main`에 올리면 Cloudflare Workers Builds가 자동으로 배포합니다(무료 플랜, Durable Object SQLite에 저장되어 데이터 유지).
직접 배포: `npm run deploy` (wrangler 로그인 필요).

## 내 컴퓨터에서 시험 (개발용)

Node.js 22.13 이상.

```bash
npm install
npm start        # http://localhost:3000, 관리자 주소는 서버 창에 표시
npm run dev:cf   # Cloudflare와 같은 환경(wrangler dev)
```

## 링크 데모 (혼자 플레이)

`node demo/build.mjs` → `demo/dist/` 에 서버 없이 브라우저만으로 돌아가는 혼자 플레이 버전이 만들어져요.
같은 게임 엔진을 브라우저 안에서 돌리고, 저장은 그 브라우저(localStorage)에 해요. 파티·관리자·해킹 방지는 실제 서버 버전에서만 동작해요.

## 보안 설계

- 비밀번호는 PBKDF2-SHA256(10만 회)+소금으로만 저장, 로그인 시도 제한. 세션 토큰은 해시만 DB에 저장, 쿠키 `HttpOnly; SameSite=Strict`(+https면 `Secure`)
- 모든 POST와 웹소켓은 같은 출처(Origin)만 허용 → CSRF·웹소켓 하이재킹 차단
- CSP(인라인 스크립트 금지), 화면에 사용자 글자는 항상 textContent로 넣어 XSS 차단
- 웹소켓: 메시지 크기 4KB 제한, 메시지 종류별 형식·범위 검증, 초당 40개 제한, 위반 누적 시 연결 차단, IP당 연결 수 제한, 중복 접속 시 이전 연결 종료
- 게임 판정: 이동은 서버가 한 틱에 입력 하나만 적용(속도핵 불가), 쿨타임·자원·스킬 해금·사거리·NPC 거리·안전 구역 여부를 모두 서버가 확인, 드롭·강화는 암호학적 난수
- 관리 API는 관리자 로그인(시도 5회 실패 시 10분 잠금)으로만 사용, 모든 관리 행동은 기록
- 위반·실패 기록은 관리자 페이지 보안 로그에서 확인

## 기획서에 없어서 정한 것

- **장착 칸**: 8칸 (좌클릭·우클릭·Q·E·R·F·Shift·V), 마을·안전 구역에서만 교체
- **성장 단계 오르는 조건**: 레벨. 전직 기준 레벨 10부터 110까지를 직업 단계 수로 나눠 배치(단계 많은 직업은 단계당 상승 폭이 작음, 마지막 단계 총 +40%)
- **스킬 해금**: 일반은 바로, 희귀·영웅·전설은 직업 단계의 10%·25%·45% 지점
- **기본 공격 추가**: 궁수 '기본 사격', 도적 '단검 베기' (기획서에 평타가 없어 조작감을 위해 추가)
- **자원**: 검사·권투사 내력(0~100, 초당 수급 상한 30), 성직자 성광(0~100, 초당 20), 대장장이 부품(0~3), 도적 틈(0~3), 나머지 MP
- **검사 자세 전환**: 다른 자세 스킬을 쓰면 그 스킬 피해 +15%, 내력 +10
- **보스 제어**: 기절·다운·속박은 면역, 대신 그로기 게이지 누적 → 100이면 3초 그로기(받는 피해 +25%)
- **일반 몬스터 제어 감쇠**: 제어가 끝난 뒤 3.5초 제어 면역
- **층 진행**: 큰 투기장 하나에 몬스터가 웨이브로 몰려옴(층당 3~6웨이브, 24~60마리), 90% 처치 시 출구 포탈 열림, 10층 보스 처치 시 다음 체크포인트(11, 21 … 91층)에서 시작 가능
- **사망**: 파티가 다음 층으로 가면 50% 체력으로 부활, 전멸하면 마을로 귀환(아이템 손실 없음)
- **드롭**: 일반 몬스터 7%, 정예 35%, 중간보스 1~2개, 주요 보스 2~3개. 등급 확률(일반/정예/보스) 62·26·9·2.5·**0.5** / 40·38·16·5.5·**0.5** / 22·42·26·9.5·**0.5**
- **신화 고유 효과 8종**: 처치 시 이속 +15%(2초), 치명타 시 15% 번개, HP 30% 이하 피해 -10%, 피해 1.5% 흡혈(초당 상한), 처치 시 MP 3%, 12초마다 5% 보호막, HP 50% 이하 피해 +8%, 10% 화상
- **강화**: 단계마다 기본 능력치 +2%, 비용은 골드(레벨·단계·등급에 비례), 마을 대장장이 근처에서만
- **전직 시 장비**: 새 직업이 못 쓰는 무기·보조장비는 가방으로, 직업 기본 무기 지급
- **스탯 재분배**: 전직 때 1회 무료(기획서), 그 외에는 훈련 교관에게 골드로 초기화
- **경험치**: 레벨이 대략 층 × 0.8을 따라가도록. 레벨 상한 150

## 던전 규칙
- 층의 몬스터를 **모두** 처치해야 출구가 열려요. 끝까지 숨어 있는 몬스터는 8초마다 근처로 불려 와요.
- 매 층 시작 지점 옆에 **마을로** 포탈이 있어요(1.5초 서 있으면 혼자 귀환).
- 한 번 깬 보스층(5·10·15…)은 문지기에게서 **보스 재도전**으로 다시 갈 수 있어요(파티는 모두 깬 층만).
- 파티는 누군가 출구에 서면 **이동 투표**가 열리고, 전원 동의(Y/N 또는 버튼)해야 다음 층으로 가요.
