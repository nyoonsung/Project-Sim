# Project-Sim — 2D 픽셀 던전 RPG

모험가로 시작해 1~100층 던전을 공략하는 웹 브라우저 멀티플레이 RPG.
전투는 **서버가 전부 계산**하고 브라우저는 입력만 보내는 구조라 클라이언트 조작(속도핵·데미지 조작 등)이 통하지 않습니다.

- 7직업(검사·권투사·궁수·도적·마법사·성직자·대장장이) + 모험가, 기획서 스킬 전부(공용 4 + 직업 스킬 101개)
- 1~100층, 5층마다 중간보스·10층마다 주요 보스(총 20종, 예고 장판·탄막·돌진·회전 광선 등 패턴), 10층 전직소
- 솔로 / 최대 4인 실시간 파티, 개인 드롭
- 장비 5부위, 등급 일반·희귀·영웅·전설·신화(0.5%), **쿨타임 감소 효과 없음**
- 강화 +99까지: +n→+n+1 성공 (99−n)%, 파괴 항상 1%
- GM 패널(`/gm`): 서버 현황, 플레이어 검색·수정·아이템 지급/회수·킥·차단·채금·층 이동·비밀번호 재설정·권한, 공지, GM 감사 기록, 보안 로그
- 그래픽: [pixelfx](https://github.com/patch-gg/pixelfx)(MIT) 이펙트와 픽셀 캐릭터 리그, [Galmuri](https://github.com/quiple/galmuri)(OFL) 픽셀 폰트

## 내 컴퓨터에서 실행

Node.js **22.13 이상**이 필요합니다 (내장 SQLite 사용, 별도 DB 설치 없음).

```bash
npm install
INITIAL_GM_USER=관리자아이디 INITIAL_GM_PASS=비밀번호123 npm start
```

Windows PowerShell:

```powershell
npm install
$env:INITIAL_GM_USER="관리자아이디"; $env:INITIAL_GM_PASS="비밀번호123"; npm start
```

- 게임: http://localhost:3000
- GM 패널: http://localhost:3000/gm (또는 게임 안 도움말(H) → GM 패널 열기)
- `INITIAL_GM_*`는 처음 한 번만 필요합니다. 나중에 GM을 추가하려면 `npm run create-gm -- 아이디 비밀번호`

## 링크 데모 (혼자 플레이)

`node demo/build.mjs` → `demo/dist/` 에 서버 없이 브라우저만으로 돌아가는 혼자 플레이 버전이 만들어져요.
같은 게임 엔진을 브라우저 안에서 돌리고, 저장은 그 브라우저(localStorage)에 해요. 파티·GM·해킹 방지는 실제 서버 버전에서만 동작해요.

## 서버 배포 (GitHub Pages로는 안 됨)

GitHub Pages는 정적 파일만 올리는 곳이라 이 게임 서버를 돌릴 수 없습니다. 코드는 GitHub에 두고, 서버는 Node.js를 돌릴 수 있는 호스팅에 올려야 합니다.

**Render 예시** (`render.yaml` 포함)
1. render.com 가입 → New → Blueprint → 이 GitHub 저장소 선택
2. 환경 변수 `INITIAL_GM_USER`, `INITIAL_GM_PASS` 입력
3. 배포가 끝나면 `https://<이름>.onrender.com` 에서 접속

⚠ 저장 데이터(SQLite 파일)는 `DB_PATH` 위치에 저장됩니다. Render 무료 플랜은 디스크가 재배포 때마다 초기화되므로, 계정·캐릭터를 계속 보존하려면 **영구 디스크가 있는 유료 플랜**(render.yaml의 disk 설정)이나 영구 저장소가 있는 다른 호스팅이 필요합니다.

환경 변수

| 이름 | 설명 |
|---|---|
| `PORT` | 포트 (기본 3000) |
| `DB_PATH` | DB 파일 경로 (기본 `data/game.db`) |
| `INITIAL_GM_USER` / `INITIAL_GM_PASS` | 첫 실행 때 GM 계정 생성 |
| `SECURE_COOKIES=1` | https 배포 시 (NODE_ENV=production이면 자동) |
| `TRUST_PROXY=1` | 프록시 뒤에서 실제 IP 기록 (Render는 자동) |
| `ALLOWED_ORIGINS` | 추가로 허용할 출처(쉼표 구분) |
| `REGISTRATION_OPEN=0` | 가입 막기 |

## 보안 설계

- 비밀번호 scrypt 해시, 세션 토큰은 해시만 DB에 저장, 쿠키 `HttpOnly; SameSite=Strict`(+https면 `Secure`)
- 로그인 시도 제한(IP·계정별 잠금), 가입 시도 제한, 계정 존재 여부가 드러나지 않는 응답 시간
- 모든 POST와 웹소켓은 같은 출처(Origin)만 허용 → CSRF·웹소켓 하이재킹 차단
- CSP(인라인 스크립트 금지), 화면에 사용자 글자는 항상 textContent로 넣어 XSS 차단
- 웹소켓: 메시지 크기 4KB 제한, 메시지 종류별 형식·범위 검증, 초당 40개 제한, 위반 누적 시 연결 차단, IP당 연결 수 제한, 중복 접속 시 이전 연결 종료
- 게임 판정: 이동은 서버가 한 틱에 입력 하나만 적용(속도핵 불가), 쿨타임·자원·스킬 해금·사거리·NPC 거리·안전 구역 여부를 모두 서버가 확인, 드롭·강화는 암호학적 난수
- GM API는 서버에서 권한 확인, 모든 GM 행동은 감사 기록, 다른 GM 차단·강등 불가
- 위반·실패 기록은 GM 패널 보안 로그에서 확인

## 기획서에 없어서 정한 것

- **장착 칸**: 8칸 (좌클릭·우클릭·Q·E·R·F·Shift·V), 마을·안전 구역에서만 교체
- **성장 단계 오르는 조건**: 레벨. 전직 기준 레벨 10부터 110까지를 직업 단계 수로 나눠 배치(단계 많은 직업은 단계당 상승 폭이 작음, 마지막 단계 총 +40%)
- **스킬 해금**: 일반은 바로, 희귀·영웅·전설은 직업 단계의 10%·25%·45% 지점
- **기본 공격 추가**: 궁수 '기본 사격', 도적 '단검 베기' (기획서에 평타가 없어 조작감을 위해 추가)
- **자원**: 검사·권투사 내력(0~100, 초당 수급 상한 30), 성직자 성광(0~100, 초당 20), 대장장이 부품(0~3), 도적 틈(0~3), 나머지 MP
- **검사 자세 전환**: 다른 자세 스킬을 쓰면 그 스킬 피해 +15%, 내력 +10
- **보스 제어**: 기절·다운·속박은 면역, 대신 그로기 게이지 누적 → 100이면 3초 그로기(받는 피해 +25%)
- **일반 몬스터 제어 감쇠**: 제어가 끝난 뒤 3.5초 제어 면역
- **층 진행**: 몬스터 70% 처치 시 출구 포탈 열림, 10층 보스 처치 시 다음 체크포인트(11, 21 … 91층)에서 시작 가능
- **사망**: 파티가 다음 층으로 가면 50% 체력으로 부활, 전멸하면 마을로 귀환(아이템 손실 없음)
- **드롭**: 일반 몬스터 7%, 정예 35%, 중간보스 1~2개, 주요 보스 2~3개. 등급 확률(일반/정예/보스) 62·26·9·2.5·**0.5** / 40·38·16·5.5·**0.5** / 22·42·26·9.5·**0.5**
- **신화 고유 효과 8종**: 처치 시 이속 +15%(2초), 치명타 시 15% 번개, HP 30% 이하 피해 -10%, 피해 1.5% 흡혈(초당 상한), 처치 시 MP 3%, 12초마다 5% 보호막, HP 50% 이하 피해 +8%, 10% 화상
- **강화**: 단계마다 기본 능력치 +2%, 비용은 골드(레벨·단계·등급에 비례), 마을 대장장이 근처에서만
- **전직 시 장비**: 새 직업이 못 쓰는 무기·보조장비는 가방으로, 직업 기본 무기 지급
- **스탯 재분배**: 전직 때 1회 무료(기획서), 그 외에는 훈련 교관에게 골드로 초기화
- **경험치**: 레벨이 대략 층 × 0.8을 따라가도록. 레벨 상한 150

## 폴더 구조

```
server/            Node 서버 (main.js 진입점)
  auth.js db.js gm.js net.js config.js
  game/            world(접속·파티·상점·강화·전직) room(시뮬레이션) skills(스킬 엔진)
                   ai(몬스터·보스) combat(피해·치명타·상태이상) dungeon(층 생성) player
shared/            서버·브라우저 공용 데이터 (직업·스킬·몬스터·아이템·이동 판정)
public/            브라우저 (index.html 게임, gm.html GM 패널)
  js/render/       타일·캐릭터 리그·pixelfx 이펙트·조명
  js/ui/           HUD·창·툴팁
  vendor/pixelfx/  이펙트 라이브러리 (MIT, LICENSE·NOTICE 포함)
tools/             bot-test.js(통합 테스트) sim.js(밸런스 시뮬) skill-sweep.js(전 스킬 실행) create-gm.js
```
